# 跨境电商物流

## 物流方式选择
常见跨境物流方式包括国际小包（成本低、时效慢）、专线物流（成本与时效折中）、海外仓（时效快、需提前备货）。选择时按品类重量、客单价与目标市场权衡。

## 时效与成本
物流时效直接影响转化率与退货率，页面上应展示合理的承诺时效。成本包括头程运输、尾程派送、海外仓储等；低价小件适合小包直邮，大件重货适合海外仓备货。

## 物流跟踪与异常
发货后提供物流单号供买家查询轨迹。出现丢件、破损、延误时，按平台规则处理退款、补发或理赔，并保留发货与签收凭证。

## 退换货
跨境退货成本较高。常见做法是低价商品退款不退货、高价商品退回目的国退货仓；在店铺明确退货政策能减少客诉与纠纷。
